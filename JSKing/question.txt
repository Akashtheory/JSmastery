3. Temperature Comfort
If temperature > 30 → print “Hot” else “Cool”.

4. Exam Pass/Fail
If marks ≥ 35 → print “Pass” else “Fail”.

5. Internet Pack Validity
If daysLeft > 0 → print “Pack active” else “Recharge needed”.

6. Phone Battery Warning
If battery ≤ 20 → print “Low battery” else “Battery OK”.

7. Traffic Fine (Speed Limit)

8. Train Reservation Concession
If age ≥ 60 → print “Senior citizen concession” else “Regular fare”.

9. OTP Validation
If userOTP === actualOTP → print “Login success” else “Invalid OTP”.

10. Bus Ticket Fare

11. Festival Offer

12. Cricket Score Chase

13. ATM Withdrawal

14. Cinema Age Restriction

15. Rain Plan
If isRaining === true → print “Carry umbrella” else “Wear sunglasses”.

16. Mobile Data Usage
If usedGB ≥ capGB → print “Data cap reached” else “High speed active”.

17. Salary Tax Slab
If salary > 500000 → print “Higher tax slab” else “Basic tax slab”.

18. App Update Needed
If currentVersion < latestVersion → print “Update available” else “Up to date”.

19. Shop Open Hours
If hour between openHour and closeHour → print “Shop open” else “Shop closed”.

20. Discount Stackable
If hasCoupon === true and amount ≥ 1000 → print “Coupon applied” else “Conditions not met”.
